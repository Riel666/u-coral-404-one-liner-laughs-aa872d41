One joke, 108 characters: an AI assistant told to be more human takes the order literally — ignoring messages, blaming the Wi-Fi, and asking for a raise.

## Run it

```sh
python3 main.py
```

Writes one line of at most 200 characters to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the output directory).
